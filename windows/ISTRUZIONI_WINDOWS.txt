============================================================
  CONTA POLLINICA - ISTRUZIONI PER WINDOWS
============================================================


OPZIONE 1: CREARE L'ESEGUIBILE (CONSIGLIATA)
---------------------------------------------
Questa opzione crea un file .exe che funziona su qualsiasi
PC Windows senza dover installare nulla.

PASSI (da fare UNA SOLA VOLTA su un PC con internet):

  1. Installa Python da: https://www.python.org/downloads/
     IMPORTANTE: durante l'installazione, spunta la casella
     "Add Python to PATH" nella prima schermata.

  2. Copia l'intera cartella "windows" su quel PC.

  3. Fai doppio clic su "build_exe.bat" e attendi.
     Lo script installa le dipendenze e crea l'eseguibile.

  4. Al termine, troverai il file:
       windows\Conta_Pollinica.exe

  5. Copia "Conta_Pollinica.exe" dove vuoi (desktop,
     chiavetta USB, cartella condivisa...).
     Il template Excel e' gia' incluso dentro il .exe.

  6. Per usarlo: doppio clic su Conta_Pollinica.exe.
     Al primo avvio chiede in quale cartella salvare i file
     della stagione (si puo' cambiare dalla schermata iniziale);
     la scelta e' ricordata nel file pollencounter.cfg, che
     compare accanto all'eseguibile.

  LETTURA VOCALE: l'exe gia' pronto (windows\Conta_Pollinica.exe)
  la include. Se lo ricompili con build_exe.bat, la voce viene
  inclusa solo se prima metti il modello vocale in codice\modelli
  (vedi la sezione LETTURA VOCALE piu' sotto); senza modello
  l'exe funziona ma senza voce.


OPZIONE 2: USARE DIRETTAMENTE CON PYTHON
-----------------------------------------
Se il PC ha gia' Python installato:

  1. Installa la dipendenza (una sola volta):
       pip install openpyxl

  2. Fai doppio clic su "AVVIA_CONTA_POLLINICA.bat"
     (installa openpyxl automaticamente se mancante,
     poi apre l'interfaccia grafica).

     In alternativa, da Prompt dei comandi:
       python polline_counter_gui.py

  Per la lettura vocale: pip install vosk sounddevice pyttsx3
  e il modello in codice\modelli (vedi LETTURA VOCALE). Se il modello
  e' gia' in codice\modelli, AVVIA_CONTA_POLLINICA.bat installa da solo
  le librerie mancanti.

  Versione da terminale (stessi comandi della GUI, non ha la voce):
  doppio clic su "AVVIA_CONTA_POLLINICA_CLI.bat".

  Nota: tutti i file della cartella "codice/" (i moduli .py
  polline_counter.py, polline_counter_gui.py, dominio.py,
  sessione.py, esportatori.py, percorsi.py, voce.py, il template
  "Polline_Template_Settimanale.xlsx", il file soglie
  "concentrazioni_polliniche.xlsx" e i due template dei
  bollettini .docx) devono trovarsi nella stessa cartella.


INTERFACCIA GRAFICA
--------------------
All'avvio compare una schermata iniziale con la cartella di lavoro,
l'elenco delle sessioni interrotte e dei file .xlsx gia' salvati, e
un campo per iniziare un file nuovo scegliendo la settimana.

Scelto un file o una sessione, si passa alla schermata di lavoro,
divisa in due pannelli:

  PANNELLO SINISTRO
    In alto, i pulsanti LUN...DOM per scegliere il giorno su cui
    lavorare. Sotto, il riquadro con lo storico delle operazioni e,
    in basso, la casella "Codice:" dove digitare codici e comandi
    (si conferma con Invio o col pulsante "Invia"). I pulsanti
    Correggi / Nota / Annulla / Salva / Chiudi giornata / Chiudi
    settimana fanno le stesse cose dei comandi da tastiera.

  PANNELLO DESTRO - Riepilogo live
    Si aggiorna immediatamente a ogni inserimento (non e' piu' un
    aggiornamento periodico: la GUI legge lo stesso stato in memoria
    usato per salvare, senza rileggere il file).

    Scheda "Settimanale": totale per specie sull'intera
      settimana, con subtotali pollini / spore / TOTALE.

    Scheda "Giornaliero": griglia specie x giorno (lun-dom)
      con subtotali per ciascun giorno.

    Nelle due schede, per le famiglie che sono la somma di piu' specie
    (Betulaceae, Compositae, Corylaceae, Fagaceae, Oleaceae, Salicaceae)
    compare una riga grigia in grassetto "NOME (totale)" con la somma di
    specie e "dubbi"; la riga del codice di famiglia diventa "NOME
    (dubbi)" (granuli di cui non si e' stabilita la specie). I totali
    Pollini / Spore / TOTALE non contano due volte.

    Scheda "Bollettino": anteprima del bollettino pollinico, con
      ogni giorno colorato secondo la propria concentrazione
      (stessa logica usata per generare il bollettino Word: quello
      che si vede qui e' quello che verra' pubblicato).


UTILIZZO DEL PROGRAMMA
-----------------------
  PASSO 1 - Scegliere sessione, file o nuovo
    Nella schermata iniziale: doppio clic (o "Riprendi selezionato")
    su una sessione/file dall'elenco, "Apri un file da un'altra
    cartella..." per un file fuori dalla cartella di lavoro, oppure
    scegli la settimana e premi "Inizia nuova settimana".
    Formati data accettati (giorno e mese anche senza zero):
      9-2-2026    09/02/2026    9 feb 2026

  PASSO 2 - Scegliere il giorno
    Clic su uno dei pulsanti LUN...DOM in alto a sinistra.

  PASSO 3 - Inserire i dati
    Digita il codice specie (01-59) nella casella in basso e premi
    INVIO. Il totale nell'etichetta del giorno si aggiorna a ogni
    inserimento, e le tre schede a destra si aggiornano insieme.


COMANDI DISPONIBILI
--------------------
Si digitano nella casella di inserimento, esattamente come nella CLI.

  01-59       Inserisce la specie corrispondente
  NNxQ        Inserisce Q occorrenze (es. 48x4 = 4 Alternaria)
  .           Ripete l'ultimo codice inserito
  u           Annulla l'ultimo inserimento
  r           Porta in primo piano la scheda Giornaliero
  w           Porta in primo piano la scheda Settimanale
  l           Ultimi 10 inserimenti (storico)
  c           Apre la finestra "Correggi un giorno"
  n           Chiede una nota testuale per la giornata corrente
  b           Attiva/disattiva il beep sonoro
  h           Mostra l'elenco dei comandi
  d           Chiude la giornata (bisogna sceglierne un'altra)
  s           Salva subito il file .xlsx, senza uscire
  q           Salva e chiude la settimana (torna alla schermata iniziale)

I comandi c, n, u, s, d, q sono disponibili anche come pulsanti.


FINESTRA
--------
La finestra si adatta da sola allo schermo e quando la si ridimensiona: i
pulsanti vanno a capo invece di sparire, le schede a destra (Settimanale,
Giornaliero, Bollettino, Codici) riempiono lo spazio e il divisorio fra i
due pannelli mantiene la proporzione. Il divisorio si puo' trascinare a
mano: dimensione della finestra e proporzione vengono ricordate per la
volta successiva.

MENU, SCORCIATOIE E SCHERMATA INIZIALE
---------------------------------------
Schermata iniziale: in alto, se c'e' un lavoro interrotto (chiusura
improvvisa, mancanza di corrente) compare un riquadro giallo con il
pulsante "Riprendi": i dati non sono persi. Poi "Nuova settimana" (le
frecce passano alla settimana precedente o successiva; sotto la data
compare il periodo, es. "da lunedi 12/10 a domenica 18/10/2026") e
l'elenco "Riprendi un lavoro" con la data dell'ultima modifica. In
basso: cartella di lavoro ("Cambia..." per sceglierne un'altra, "Apri"
per vederla nel gestore file), elenco codici stampabile, guida (F1) e
"Esci" per chiudere il programma.
Se per la settimana scelta esiste gia' un lavoro non salvato o un file,
il programma lo dice e propone di riprenderlo invece di ricominciare da
zero.

Barra dei menu (File, Modifica, Visualizza, Strumenti, Aiuto): ha le
stesse azioni dei pulsanti, piu' "Esci dal programma". Scorciatoie:
  Ctrl+S  salva            Ctrl+Z  annulla l'ultimo inserimento
  Ctrl+Q  esce dal programma
  Ctrl+1 ... Ctrl+4  cambia scheda a destra         F1  aiuto
Il pulsante "Chiudi settimana (q)" salva e torna alla schermata
iniziale; per uscire dal programma si usa "Esci" (schermata iniziale),
il menu File o Ctrl+Q. Beep, Voce e "Ripeti a voce" sono interruttori
(si accendono con un clic). In basso la barra di stato dice se ci sono
modifiche non salvate.

Aspetto: se e' installato il pacchetto sv-ttk la finestra ha lo stile
di Windows 11; senza funziona uguale con l'aspetto di base
(pip install sv-ttk).

LETTURA VOCALE
---------------
Permette di registrare i granuli a voce, senza staccare gli occhi dal
microscopio. Funziona senza internet: la voce non esce dal computer.

Requisiti:
  - un microfono, con l'accesso attivo in Impostazioni di Windows >
    Privacy > Microfono (anche per le "app desktop");
  - una voce italiana di Windows per la conferma parlata (Impostazioni >
    Ora e lingua > Lingua: aggiungere Italiano con la sintesi vocale);
    senza, la conta funziona ma il computer parla con voce straniera.
  - per ricompilare l'exe con la voce: scaricare "vosk-model-small-it-0.22"
    da https://alphacephei.com/vosk/models, decomprimerlo in
    codice\modelli\ e lanciare build_exe.bat (l'exe pesa ~80 MB e
    si avvia piu' lentamente: il modello viene estratto a ogni avvio).

Uso: premere il pulsante "Voce" (l'interruttore si accende). Ogni frase deve
cominciare con "conta": senza, il computer ignora tutto, cosi' le
conversazioni in laboratorio non vengono registrate. Il computer ripete a
voce il nome che ha capito; se e' sbagliato dire "conta annulla".

  conta ventiquattro          inserisce il codice 24
  conta graminacee            inserisce la specie per nome
  conta acero per tre         inserisce 3 occorrenze (da 1 a 20)
  conta annulla               annulla l'ultimo inserimento
  conta ripeti                ripete l'ultimo codice
  conta totale                il computer legge il totale del giorno

Piu' comandi di seguito: ogni "conta" chiude il comando precedente e ne
inizia uno nuovo, quindi si puo' dire "conta acero conta ontano conta
graminacee per tre" e vengono registrati tre inserimenti, nell'ordine.
Basta una pausa breve fra un comando e l'altro. Se un comando non e'
chiaro viene scartato da solo, senza perdere gli altri.

Salvare, chiudere la giornata e uscire restano solo da tastiera/pulsante.
"Ripeti a voce" spento (predefinito): si registra in silenzio, solo
"conta totale" risponde. Il microfono resta acceso mentre il computer
parla.
Il modello vocale non conosce molti nomi latini (es. alternaria,
betulacee), ma quasi tutti sono riconosciuti lo stesso grazie a pronunce
incorporate nel programma: si dicono normalmente ("conta alternaria",
"conta betulacee"). Con voci o accenti diversi puo' capitare di non essere
capiti o, raramente, di essere scambiati per un'altra specie: il computer
ripete cio' che ha capito (con "Ripeti a voce"), quindi basta dire "conta
annulla". Il log scrive anche le frasi sentite ma non riconosciute ("Sentito
ma non in elenco"): servono per aggiungere nuove varianti. In caso di
dubbio dire il numero o il nome comune; la scheda "Codici", colonna "A
voce", mostra cosa si puo' dire per ogni specie. Dettagli e personalizzazione (pollencounter.cfg:
"parola_attivazione", "sinonimi_vocali"): vedi ISTRUZIONI.txt, sezione
LETTURA VOCALE.

Stato: provata al microfono su Linux (riconosce tutte le specie); l'exe
Windows e' stato compilato e avviato sotto Wine, ma microfono e sintesi
vocale di Windows vanno ancora verificati su un PC Windows vero.


SALVATAGGIO
-----------
  File di sessione (journal)
    Ogni inserimento, annullo, correzione o nota viene scritto
    subito su un file "~sessione_<data-lunedi>.jsonl" nella cartella
    di lavoro. In caso di chiusura improvvisa (crash, mancanza di
    corrente, chiusura della finestra) nulla va perso: alla
    prossima apertura la sessione compare nell'elenco iniziale,
    pronta per essere ripresa esattamente da dove si era rimasti.

  Comando/pulsante "s" - Salvataggio rapido
    Scrive subito il file .xlsx definitivo, senza uscire dalla
    sessione. La prima volta chiede dove salvare; le volte
    successive riusa lo stesso percorso.

  Comando/pulsante "q" - Chiusura della settimana
    Chiede se salvare il file .xlsx definitivo. Se si sceglie di
    uscire senza salvare, chiede se conservare il file di sessione
    per riprenderlo in seguito. Dopo un salvataggio riuscito viene
    proposto di aggiornare anche il riepilogo annuale e/o generare
    i bollettini Word.

  Il template "Polline_Template_Settimanale.xlsx" non viene
  mai modificato.
