============================================================
  CONTA POLLINICA - ISTRUZIONI PER LINUX
============================================================

Su Linux il programma si usa direttamente dal codice Python (non c'e'
un eseguibile da creare). Le istruzioni d'uso generali (comandi, codici,
salvataggio, bollettini) sono in ISTRUZIONI.txt, nella cartella
principale del progetto; qui c'e' solo cio' che e' specifico di Linux.


INSTALLAZIONE (una sola volta)
-------------------------------
  openSUSE:
    sudo zypper install python3-tk python3-openpyxl python3-python-docx

  Debian / Ubuntu:
    sudo apt install python3-tk python3-openpyxl python3-docx

  Altre distribuzioni (o per usare pip):
    pip3 install --user openpyxl python-docx
    (tkinter si installa col pacchetto "python3-tk" della distribuzione)

  python-docx e' opzionale: serve solo per i bollettini Word.


AVVIO
-----
  Dalla cartella principale del progetto (pollencounter/):

    ./script_aiuto/AVVIA_CONTA_POLLINICA_GUI.sh     (interfaccia grafica)
    ./script_aiuto/AVVIA_CONTA_POLLINICA.sh         (da terminale)

  Se non partono: chmod +x script_aiuto/*.sh

  Gli script controllano che tkinter e openpyxl siano installati e, se
  manca qualcosa, spiegano come installarlo. Se manca python-docx o la
  parte vocale (solo se il modello e' in codice/modelli) lo segnalano
  con una "Nota", ma il programma parte comunque.

  Icona sul Desktop: crea un file ContaPollinica.desktop con
    [Desktop Entry]
    Type=Application
    Name=Conta Pollinica
    Exec=bash /PERCORSO/pollencounter/script_aiuto/AVVIA_CONTA_POLLINICA_GUI.sh
    Terminal=false
  Se sposti la cartella del progetto, aggiorna il campo Exec.


FINESTRA
--------
La finestra si adatta da sola allo schermo e quando la si ridimensiona: i
pulsanti vanno a capo invece di sparire, le schede a destra (Settimanale,
Giornaliero, Bollettino, Codici) riempiono lo spazio e il divisorio fra i
due pannelli mantiene la proporzione. Il divisorio si puo' trascinare a
mano: dimensione della finestra e proporzione vengono ricordate per la
volta successiva.

MENU, SCORCIATOIE E SCHERMATA INIZIALE
---------------------------------------
Schermata iniziale: in alto, se c'e' un lavoro interrotto (chiusura
improvvisa, mancanza di corrente) compare un riquadro giallo con il
pulsante "Riprendi": i dati non sono persi. Con piu' lavori interrotti
"Scegli o rimuovi..." apre l'elenco dei soli lavori non salvati: si puo'
riprenderne uno, rimuoverne alcuni (Ctrl o Maiusc + clic) o tutti. La
rimozione e' definitiva e chiede conferma; "Rimuovi non salvato" fa lo
stesso dall'elenco in basso e non tocca mai i file .xlsx salvati.
Poi "Nuova settimana" (le
frecce passano alla settimana precedente o successiva; sotto la data
compare il periodo, es. "da lunedi 12/10 a domenica 18/10/2026") e
l'elenco "Riprendi un lavoro", una riga per settimana (stato,
periodo, data dell'ultima modifica, righe di log e bollettini). In
basso: cartella di lavoro ("Cambia..." per sceglierne un'altra, "Apri"
per vederla nel gestore file), elenco codici stampabile, guida (F1) e
"Esci" per chiudere il programma.
Se per la settimana scelta esiste gia' un lavoro non salvato o un file,
il programma lo dice e propone di riprenderlo invece di ricominciare da
zero.

Barra dei menu (File, Modifica, Visualizza, Strumenti, Aiuto): ha le
stesse azioni dei pulsanti, piu' "Esci dal programma". Scorciatoie:
  Ctrl+S  salva            Ctrl+Z  annulla l'ultimo inserimento
  Ctrl+Q  esce dal programma
  Ctrl+1 ... Ctrl+4  cambia scheda a destra         F1  aiuto
F1 apre una finestra con i comandi, che si puo' ridimensionare (il testo si
riadatta) e lasciare aperta mentre si conta; Esc o F1 la chiudono.
Il pulsante "Chiudi settimana (q)" salva e torna alla schermata
iniziale; per uscire dal programma si usa "Esci" (schermata iniziale),
il menu File o Ctrl+Q. Beep, Voce e "Ripeti a voce" sono interruttori
(si accendono con un clic). In basso la barra di stato dice se ci sono
modifiche non salvate.

Aspetto: se e' installato il pacchetto sv-ttk la finestra ha lo stile
di Windows 11; senza funziona uguale con l'aspetto di base
(pip install sv-ttk).

LETTURA VOCALE (opzionale)
---------------------------
Permette di registrare i granuli a voce, senza staccare gli occhi dal
microscopio. Funziona senza internet. Per usarla:

  1. Librerie Python:
       pip3 install --user vosk sounddevice pyttsx3
     Se pip risponde "externally-managed-environment" (distribuzioni
     recenti) aggiungi  --break-system-packages  oppure usa un ambiente
     virtuale.
  2. Pacchetti di sistema:
       openSUSE:       sudo zypper install libportaudio2 espeak-ng
       Debian/Ubuntu:  sudo apt install libportaudio2 espeak-ng
  3. Modello italiano "vosk-model-small-it-0.22" da
       https://alphacephei.com/vosk/models
     decompresso in codice/modelli/ (deve restare una cartella
     "vosk-model-small-it-...").
  4. Un microfono funzionante (controlla il livello in Impostazioni >
     Audio).

Come si usa (parola "conta", comandi, "Ripeti a voce", personalizzazione):
vedi la sezione LETTURA VOCALE di ISTRUZIONI.txt.

Come funziona l'audio su Linux: la conferma parlata usa espeak-ng (voce
italiana) e il suono viene riprodotto con il primo programma che trova fra
paplay, pw-play e aplay; lo stesso vale per il beep (comando "b" o
pulsante "Beep"). Con PulseAudio/PipeWire c'e' di solito gia' paplay o
pw-play. Se beep e voce restano muti:
  - controlla il volume e l'uscita audio selezionata;
  - prova da terminale:  espeak-ng -v it "prova"
  - se non esce nessun suono, installa un lettore:
       sudo zypper install alsa-utils      (openSUSE)
       sudo apt install alsa-utils         (Debian/Ubuntu)
  - se la GUI scrive "Nessuna voce italiana installata", installa i dati
    italiani di espeak-ng (di solito inclusi nel pacchetto espeak-ng).

Stato: provata al microfono su Linux (openSUSE): riconosce tutte le
specie con la voce dell'utente.
