============================================================
  CONTA POLLINICA - ISTRUZIONI PER macOS
============================================================


OPZIONE 1: USARE DIRETTAMENTE CON PYTHON (CONSIGLIATA)
-------------------------------------------------------
Non richiede la creazione di un eseguibile. Funziona su
qualsiasi Mac con Python 3 installato.

PASSI:

  1. Installa Python 3 da:
       https://www.python.org/downloads/
     Scarica il pacchetto per macOS e segui l'installazione.

     In alternativa, con Homebrew:
       brew install python3

  2. Installa la dipendenza openpyxl. Apri il Terminale
     (Applicazioni > Utility > Terminale) e digita:
       pip3 install openpyxl

  3. Rendi eseguibili gli script (una sola volta):
       chmod +x AVVIA_CONTA_POLLINICA_GUI.sh
       chmod +x AVVIA_CONTA_POLLINICA.sh

  4. Avvia l'interfaccia grafica con doppio clic su:
       AVVIA_CONTA_POLLINICA_GUI.sh
     oppure da Terminale:
       ./AVVIA_CONTA_POLLINICA_GUI.sh

     Per la versione da terminale:
       ./AVVIA_CONTA_POLLINICA.sh

  Nota su tkinter: se compare l'errore "tkinter non trovato"
  e hai installato Python con Homebrew, esegui:
    brew install python-tk


OPZIONE 2: CREARE L'APPLICAZIONE .APP
--------------------------------------
Crea un'applicazione macOS che funziona con doppio clic,
senza dover aprire il Terminale ogni volta.
Da fare su un Mac con Python gia' installato.

  1. Apri il Terminale e vai nella cartella mac/:
       cd percorso/della/cartella/mac

  2. Rendi eseguibile lo script di build (una sola volta):
       chmod +x build_app.sh

  3. Esegui lo script:
       ./build_app.sh
     Lo script installa le dipendenze e crea l'applicazione.
     Richiede qualche minuto.

  4. Al termine troverai:
       mac/Conta_Pollinica.app

  5. Per usarla: doppio clic su Conta_Pollinica.app.

  6. Prima apertura su altri Mac (Gatekeeper):
     macOS blocca le applicazioni non firmate con un
     certificato Apple Developer. Per aprirla la prima volta:
       - Clic destro (o Ctrl+clic) sull'icona
       - Scegli "Apri"
       - Conferma nella finestra di avviso
     Dalla seconda apertura in poi, funzionera' normalmente.

  7. Per distribuirla: comprimi la cartella Conta_Pollinica.app
     in un archivio .zip (clic destro > Comprimi).


NOTA SUI FILE .SH (script di avvio)
-------------------------------------
Su macOS gli script .sh non si aprono con doppio clic
per default. Due possibilita':

  a) Da Terminale:
       cd /percorso/cartella/mac
       ./AVVIA_CONTA_POLLINICA_GUI.sh

  b) Aprire il file con Terminale:
       Clic destro sullo script > Apri con > Terminale


INTERFACCIA GRAFICA
--------------------
All'avvio compare una schermata iniziale con la cartella di lavoro,
l'elenco delle sessioni interrotte e dei file .xlsx gia' salvati, e
un campo per iniziare un file nuovo scegliendo la settimana.

Scelto un file o una sessione, si passa alla schermata di lavoro,
divisa in due pannelli:

  PANNELLO SINISTRO
    In alto, i pulsanti LUN...DOM per scegliere il giorno su cui
    lavorare. Sotto, il riquadro con lo storico delle operazioni e,
    in basso, la casella di inserimento (stesso prompt della CLI:
    "LUN [3] >>") dove digitare codici e comandi. I pulsanti
    Correggi / Nota / Annulla / Salva / Chiudi giornata / Esci
    fanno le stesse cose dei comandi da tastiera.

  PANNELLO DESTRO - Riepilogo live
    Si aggiorna immediatamente a ogni inserimento (non e' piu' un
    aggiornamento periodico: la GUI legge lo stesso stato in memoria
    usato per salvare, senza rileggere il file).

    Scheda "Settimanale": totale per specie sull'intera
      settimana, con subtotali pollini / spore / TOTALE.

    Scheda "Giornaliero": griglia specie x giorno (lun-dom)
      con subtotali per ciascun giorno.

    Scheda "Bollettino": anteprima del bollettino pollinico, con
      ogni giorno colorato secondo la propria concentrazione
      (stessa logica usata per generare il bollettino Word: quello
      che si vede qui e' quello che verra' pubblicato).


UTILIZZO DEL PROGRAMMA
-----------------------
  PASSO 1 - Scegliere sessione, file o nuovo
    Nella schermata iniziale: doppio clic (o "Riprendi selezionata")
    su una sessione/file dall'elenco, "Importa..." per un file in
    un'altra cartella, oppure inserisci la settimana e premi
    "Nuovo file dal template".
    Formati data accettati (giorno e mese anche senza zero):
      9-2-2026    09/02/2026    9 feb 2026

  PASSO 2 - Scegliere il giorno
    Clic su uno dei pulsanti LUN...DOM in alto a sinistra.

  PASSO 3 - Inserire i dati
    Digita il codice specie (01-59) nella casella in basso e premi
    INVIO. Il totale nell'etichetta del giorno si aggiorna a ogni
    inserimento, e le tre schede a destra si aggiornano insieme.


COMANDI DISPONIBILI
--------------------
Si digitano nella casella di inserimento, esattamente come nella CLI.

  01-59       Inserisce la specie corrispondente
  NNxQ        Inserisce Q occorrenze (es. 48x4 = 4 Alternaria)
  .           Ripete l'ultimo codice inserito
  u           Annulla l'ultimo inserimento
  r           Porta in primo piano la scheda Giornaliero
  w           Porta in primo piano la scheda Settimanale
  l           Ultimi 10 inserimenti (storico)
  c           Apre la finestra "Correggi un giorno"
  n           Chiede una nota testuale per la giornata corrente
  b           Attiva/disattiva il beep sonoro
  h           Mostra l'elenco dei comandi
  d           Chiude la giornata (bisogna sceglierne un'altra)
  s           Salva subito il file .xlsx, senza uscire
  q           Salva ed esci dalla sessione

I comandi c, n, u, s, d, q sono disponibili anche come pulsanti.


SALVATAGGIO
-----------
  File di sessione (journal)
    Ogni inserimento, annullo, correzione o nota viene scritto
    subito su un file "~sessione_<data-lunedi>.jsonl" nella cartella
    di lavoro. In caso di chiusura improvvisa (crash, chiusura della
    finestra) nulla va perso: alla prossima apertura la sessione
    compare nell'elenco iniziale, pronta per essere ripresa
    esattamente da dove si era rimasti.

  Comando/pulsante "s" - Salvataggio rapido
    Scrive subito il file .xlsx definitivo, senza uscire dalla
    sessione. La prima volta chiede dove salvare; le volte
    successive riusa lo stesso percorso.

  Comando/pulsante "q" - Uscita
    Chiede se salvare il file .xlsx definitivo. Se si sceglie di
    uscire senza salvare, chiede se conservare il file di sessione
    per riprenderlo in seguito. Dopo un salvataggio riuscito viene
    proposto di aggiornare anche il riepilogo annuale e/o generare
    i bollettini Word.

  Il template "Polline_Template_Settimanale.xlsx" non viene
  mai modificato.
